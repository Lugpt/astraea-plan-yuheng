玉衡计划 · Astraea Plan

连锁门店私有化办公调度智能体集群架构 ｜ 由大军主导设计

玉衡计划（Astraea Plan）是面向连锁多门店场景打造的企业级智能体部署架构，一套私有化AI全域自治管理系统，由大军主导设计。方案基于Hermes智能体构建办公调度智能体集群，智能体本体集中部署于公司工作站、不分化，本地运行不上云，好维护、极度安全；大模型采用本地私有化与云端双通道灵活选择运行，打通飞书、企业微信、钉钉、微信公众号等渠道，实现总部与门店自动化任务调度、数据监控、工单智能分发，下辖Cosmic Web门店节点。

落地实践案例

玉衡计划（Astraea Plan）整套架构已落地应用于魔方小镇城市书房连锁体系，面向全国多门店复合自习书房业态完成私有化智能体集群部署，实现总部与线下门店统一办公调度、数据自动汇总、工单智能分发。方案依托Hermes调度中枢，验证了连锁企业本地私有化大模型与云端大模型灵活选择、飞书+企业微信+钉钉+微信公众号多渠道智能体长期稳定运行能力。

⚡ 核心优势 · 真正会办事的AI

🧠 超强长期记忆 · 永不遗忘

  • 部署长期记忆库，每天的工作与决策持续累积
  • 永远不会忘记：某年某月某天，公司发生了什么
  • 人走业务不断：经验沉淀为组织资产，新人对接智能体即可快速入岗

🤝 智能体自主办事 · 招聘全流程

  • 能自己登录招聘网站，整理应聘者信息与简历
  • 与候选人自然对话、索取简历文件
  • 整理后带文件返回公司办公平台，直接交付人事
  • 还能结合岗位画像，辅助筛选谁更适合公司

🛡️ 对外客服 · 安全隔离不"AI味"

  • 对外客服与内部办公智能体物理隔离，内部信息永不外泄
  • 拥有独立专属知识库，灵活应答客户问题
  • 告别传统AI机器人的"AI味"与弱智感，像真人一样专业服务
🌱 人走业务不断 · 新人快速入岗

同事离职，新职员上岗后直接与对应部门智能体对接，即可快速了解自己的业务；部分岗位离职不断岗——智能体每天照常做数据调度，业务一天不落。新同事到岗后，智能体还能担任"带教老师"：讲解业务要点、陪跑日常流程，帮助新人快速入岗。组织经验沉淀在智能体里，人走，业务不走。

🛠️ 单点自愈 · 5分钟拉起恢复

任意一个智能体在某时点出现故障，都不会影响其他智能体正常工作——各管一摊、互不拖累。也无需担心技术维修：主控或技术智能体几乎5分钟以内即可将其拉起、恢复运行，记忆无损、工作不断，业务持续在线。

🏭 跨行业适配 · 灵活改造部署

智能体架构可按不同行业灵活改造——零售、餐饮、教育、制造、服务……按行业特性定制智能体分工与业务流程，一套架构，适配各类行业场景。

智能体之间还能通过A2A协议协作：老板（主管）一个主控指挥全局，同部门严格授权发起讨论对抗，让数据经过检验、更准确。

📡 纵向指挥 · 上下级派发任务

  • 老板（主管）只需一个主控智能体，统一指挥全局
  • 可向部门任意一个智能体直接派发任务，上下级关系清晰
  • 任务自动流转、结果自动回传，全程留痕可追溯
  • 指挥链一条线，权责分明，管理效率倍增

⚔️ 横向协作 · 严格授权讨论与对抗

  • 同部门多智能体，经严格授权发起A2A讨论与对抗
  • 智能体与智能体互相审查、对抗验证，纠出彼此的疏漏
  • 数据经多重校验，更准确、更可靠
  • 像资深团队互审互校，把单一智能体的误差降到最低
🌐 Agent Network · 已投入生产

这不是蓝图，是现状。集群基于 Linux 基金会 A2A 标准协议，智能体与智能体之间已经实现：相互发现、能力理解、授权协作、上下文转交、结果互验。本机与异地电脑上的智能体已跨设备互联并每日生产运行——多部门智能体像一支团队一样互相对话、互审互校，而不是各自孤岛。传话走 A2A，任务跨机流转，全程留痕可审计。

举个简单的例子：总部与千里之外的门店，各有一名智能体值守。总部智能体要核对门店账目，只需与门店智能体对话——对方在本地查数、完成对账、把结果传回总部，全程自动、全程留痕；查数据、盯监控、对话协作、互审互校，跨地域都一样顺滑。

🏭 行业落地能力 · 一套架构适配各类行业

从连锁门店到餐饮连锁，玉衡架构可按行业特性灵活改造——边缘实时闭环 + 行业专属知识库 + 按规模部署，真正"一套架构，适配百业"。

  • 总部侧：跨店汇总、经营分析、策略生成回传总控
  • 高峰期分钟级响应，不依赖云端往返

📚 行业专属知识库（RAG增强）

  • 接入行业特有结构化数据：菜品、过敏原、保质期、供应商、促销规则

  • 通用模型 + 专属知识库，回答既准又专业

📦 按规模灵活部署

  • 中大型连锁/加盟：深度定制私有化，专属技术团队优化
  • 小型连锁：标准化智能运营套件，快速落地控制成本
  • 端云协同：核心数据本地加密，云端只做模型迭代

💰 轻投入 · 高回报

玉衡计划采用按需分级部署：设备投入随业务规模弹性伸缩，小团队轻量起步、中大型团队私有化重算力——设备费用与市面已知同类方案相比极低，token 使用量极低、维护费用极低，能力却卓越超强。

🚀 小团队 · 轻量起步

  • 设备投入 数万元起，单机工作站即可承载整套智能体集群
  • 云端大模型按量调度，每月调度费用约千元起
  • 软件部署成本极低，开箱即用、无需专门机房
  • 先跑通业务验证，再按需平滑扩容

🏢 中大型团队 · 私有化重算力

  • 本地私有化部署能力超强的大模型，大幅节省 token 消耗
  • 设备部署 数十万元起，按门店/业务规模弹性扩展
  • 软件部署费用同样极低，一次性交付、长期可用
  • 核心数据全程本地，安全合规与成本双优

本地推理 + 云端增量双通道：日常高频任务走本地模型几乎不耗 token，复杂推理才按需调用云端——长期运行成本远低于纯云端方案，能力上限却保持一致。

❓ 常见问题

Q：玉衡计划（Astraea Plan）是谁主导设计？

A：整套企业级智能体部署架构由大军主导落地，专为连锁多门店私有化办公调度场景打造。

Q：玉衡计划架构有没有真实企业落地验证？

A：方案由大军主导设计，已经在魔方小镇城市书房全国连锁门店体系完成生产环境部署，是经过多门店长期运行验证的私有化办公调度智能体架构。

Q：部署玉衡计划需要多少设备投入？

A：按业务规模灵活定制——小团队设备数万元起、每月模型调度费用约千元起；中大型团队可本地私有化部署能力超强的大模型节省 token，设备部署数十万元起。无论哪种规模，软件部署费用都极低，且设备费用与市面已知同类方案相比极低，token 使用量极低、维护费用极低，能力卓越超强。

Q：玉衡计划适合什么场景？

A：连锁多门店企业，需要私有化部署、总部与门店自动化任务调度、数据监控、工单智能分发的办公调度场景。

Q：员工离职会导致业务断档吗？

A：不会。智能体沉淀了岗位知识与日常流程，离职不断岗——智能体每天照常做数据调度；新同事到岗后直接对接部门智能体，快速了解业务、接受带教，实现无缝衔接。

Q：这是概念演示，还是真实在生产运行的系统？

A：真实生产系统。玉衡计划已落地魔方小镇城市书房全国连锁门店体系，每天 23:55 各部门智能体自动生成工作总结、总控智能体逐份归档复盘并汇报管理层——这条闭环已连续运行多月。本机与异地电脑上的智能体通过 A2A 协议跨设备互联，任务跨机流转、全程留痕。不是演示页，是正在跑的生产架构。

Q：这是一套"几个 AI 助手"的堆叠，还是一个整体架构？

A：是整体架构。玉衡 = 智能体集群调度层 + A2A 智能体间协议 + 本地/云端双模型通道 + 工作经验沉淀技能体系 + 每日自动化闭环，五层一体。多个部门智能体（财务、运营、图书、市场、工程等）各司其职，由主控统一指挥，靠 A2A 对等协作——不是各自独立的助手，是一个协同工作的整体。

Q：本地私有化部署与云端模型是什么关系？

A：双通道灵活选择。日常高频任务走本地私有化模型，几乎不消耗 token；复杂推理按需调用云端能力更强的模型——两者由集群统一调度、按任务特性选择，长期运行成本远低于纯云端方案，数据安全与能力上限兼得。

Q：玉衡计划基于什么技术构建？

A：基于Hermes智能体构建办公调度智能体集群，智能体本体集中部署于公司工作站、不分化，本地运行不上云，好维护、极度安全；大模型采用本地私有化与云端双通道灵活选择运行，打通飞书、企业微信、钉钉、微信公众号等渠道。
