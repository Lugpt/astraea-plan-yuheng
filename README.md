# 玉衡计划 · Astraea Plan

> **企业级智能体部署架构** — 面向连锁多门店场景的私有化 AI 全域自治管理系统
>
> 设计者：大军 ｜ 已生产落地：魔方小镇城市书房（188 家门店 / 20 省 / 50 城市）

## 🎯 这是什么

玉衡计划（Astraea Plan）是一套 **企业级智能体集群架构**，解决"Agent 一多就失控"的企业级问题：

- **谁负责调度** → 主控智能体统一指挥
- **谁调用谁** → 星型拓扑 + A2A 对等协作
- **任务失败怎么办** → 单点自愈，5 分钟内拉起
- **上下文怎么恢复** → 永久记忆库，人走业务不断
- **权限怎么隔离** → 部门垂直隔离，物理隔离不泄密
- **怎么审计** → 全链路日志 + 每日闭环复盘

## 🏗️ 核心架构

```text
                    ┌─────────────────┐
                    │   总控智能体    │  统一调度/学习/沉淀/汇报
                    └────────┬────────┘
           ┌────────────────┼────────────────┐
           ▼                ▼                ▼
     ┌──────────┐    ┌──────────┐    ┌──────────┐
     │ 内部办公  │    │  对外    │    │  门店    │
     │  智能体   │    │  智能体  │    │  智能体  │
     └──────────┘    └──────────┘    └──────────┘
       财务/运营         招聘/客服        数据/物料
       图书/市场         物理隔离         实时管控
```

## ✨ 关键能力

| 能力 | 说明 |
|:--|:--|
| **Agent Network** | 基于 Linux 基金会 A2A 标准协议，智能体间跨设备互联（已投入生产） |
| **双模型通道** | 本地私有化大模型 + 云端大模型，按任务特性灵活选择 |
| **永久记忆** | 长期记忆库持续累积，经验沉淀为组织资产 |
| **工作经验沉淀** | 技能体系随使用进化，新人对接智能体即可快速入岗 |
| **单点自愈** | 任一智能体故障 5 分钟拉起，记忆无损、工作不断 |
| **每日闭环** | 23:55 工作总结 → 23:57 总控复盘 → 23:59 管理层汇报 |

## 🚀 部署形态

| 规模 | 设备投入 | 说明 |
|:--|:--|:--|
| 小团队 | 数万元起 | 单机工作站承载整套集群，每月调度费约千元起 |
| 中大型团队 | 数十万元起 | 本地私有化部署超强模型，大幅节省 token |

软件部署成本极低，token 使用量低、维护费用低，能力对标云端旗舰模型。
